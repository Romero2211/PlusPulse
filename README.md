# Благодійна організація «Благодійний фонд «ПЛЮС ПУЛЬС»

Веб-сайт для благодійної організації «ПЛЮС ПУЛЬС», побудований на Next.js та Node.js.

## Про організацію

**Повна назва (UA):** Благодійна організація «Благодійний фонд «ПЛЮС ПУЛЬС»
**Повна назва (EN):** Charitable Organization "Charity Fund PLUS PULSE"
**Скорочена назва:** БО БФ «ПЛЮС ПУЛЬС» / CO CF "PLUS PULSE"

**Юридичний статус:** Недержавна, неприбуткова благодійна організація, що діє відповідно до законодавства України.
**Форма:** Благодійний фонд.

**Керівник / Президент Фонду:** Золотухіна Анастасія Андріївна
**Місцезнаходження:** Україна, Київська область, м. Українка

## Технології

- **Next.js 14** - React фреймворк з App Router
- **TypeScript** - типізація коду
- **React 18** - UI бібліотека
- **Node.js** - серверне середовище

## Структура проекту

```
PlusPulse/
├── app/                    # Next.js App Router
│   ├── layout.tsx         # Кореневий layout
│   ├── page.tsx           # Головна сторінка
│   └── globals.css        # Глобальні стилі
├── components/             # React компоненти
│   ├── Header.tsx         # Навігація
│   ├── Hero.tsx           # Hero секція
│   ├── About.tsx          # Про організацію
│   ├── Activities.tsx     # Діяльність
│   ├── Donate.tsx         # Допомога
│   ├── Contact.tsx        # Контакти
│   └── Footer.tsx         # Підвал
├── contexts/              # React контексти
│   └── LanguageContext.tsx # Контекст мови
├── package.json           # Залежності
├── next.config.js         # Конфігурація Next.js
├── tsconfig.json          # Конфігурація TypeScript
└── README.md              # Документація
```

## Встановлення та запуск

### Вимоги

- Node.js 20+ (рекомендовано останній LTS або Current з [nodejs.org](https://nodejs.org/))
- npm або yarn

### Кроки

1. **Встановіть залежності:**
   ```bash
   npm install
   ```

2. **Запустіть dev сервер:**
   ```bash
   npm run dev
   ```

3. **Відкрийте браузер:**
   Відкрийте [http://localhost:3000](http://localhost:3000)

### Інші команди

```bash
# Збірка для production
npm run build

# Запуск production сервера
npm start

# Перевірка коду
npm run lint
```

## Розробка

### Додавання нових компонентів

Створіть новий файл в папці `components/`:

```tsx
'use client'

export default function MyComponent() {
  return <div>My Component</div>
}
```

### Додавання перекладів

Оновіть файл `contexts/LanguageContext.tsx`:

```typescript
const translations: Record<Language, Record<string, string>> = {
  uk: {
    'my.key': 'Мій текст',
  },
  en: {
    'my.key': 'My text',
  },
}
```
