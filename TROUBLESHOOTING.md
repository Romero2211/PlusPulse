# Вирішення проблем

## Помилка `dlnk.one`

Якщо ви бачите помилку в консолі браузера:
```
Failed to load resource: net::ERR_FAILED
dlnk.one/e?id=...
```

**Це НЕ пов'язано з нашим кодом!**

### Можливі причини:

1. **Розширення браузера** - ad blocker, privacy extension, тощо
2. **Зовнішній трекер** - якийсь скрипт намагається завантажитися
3. **Кеш браузера** - старі дані можуть викликати проблеми

### Рішення:

1. **Перевірте в режимі інкогніто:**
   - Відкрийте сайт у режимі інкогніто/приватному
   - Якщо помилка зникла - це розширення браузера

2. **Очистіть кеш браузера:**
   - Натисніть `Ctrl + Shift + Delete`
   - Очистіть кеш та cookies

3. **Вимкніть розширення:**
   - Тимчасово вимкніть всі розширення
   - Перевірте, чи зникла помилка

4. **Ігноруйте помилку:**
   - Якщо сайт працює нормально, помилку можна ігнорувати
   - Вона не впливає на функціональність

## Вразливість Next.js (Known security vulnerabilities: 1, MEDIUM)

Якщо сканер (npm audit / OSV / IDE) показує вразливість для `next@14.2.35`:

- **Next.js 14.x stable не страждає від критичного CVE-2025-66478** (див. [офіційний advisory](https://nextjs.org/blog/CVE-2025-66478)).
- Щоб прибрати попередження MEDIUM і мати всі патчі безпеки, оновіть проєкт до **Next.js 15.4.10** (у `package.json` вже вказано `"next": "15.4.10"`).

**Після зміни версії Next.js виконайте локально:**

```bash
cd c:\Users\roman\.vscode\PlusPulse
npm install
npm run build
```

Якщо залишаєтесь на 14.x — встановіть явно патчену стабільну: `npm install next@14.2.35`.
